# Smart Doctor Admin

Admin and doctor portal for managing doctors, appointments, availability, and dashboards.

## Tech Stack

- React (Vite)
- Tailwind CSS
- Axios

## Environment Variables

Create a .env file in this folder:

VITE_BACKEND_URL=http://localhost:4000

## Run Locally

1. Install dependencies
   npm install
2. Start the app
   npm run dev

The app runs on the default Vite port (usually http://localhost:5174 if 5173 is used by the frontend).
