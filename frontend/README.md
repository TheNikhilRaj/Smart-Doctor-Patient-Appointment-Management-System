# Smart Doctor Frontend

Patient-facing web app for Smart Doctor Patient Appointment Management System. Users can browse doctors, book appointments, manage profiles, and complete payments.

## Tech Stack

- React (Vite)
- Tailwind CSS
- Axios

## Environment Variables

Create a .env file in this folder:

VITE_BACKEND_URL=http://localhost:4000
VITE_RAZORPAY_KEY_ID=your_razorpay_key_id

## Run Locally

1. Install dependencies
   npm install
2. Start the app
   npm run dev

The app runs on the default Vite port (usually http://localhost:5173).
